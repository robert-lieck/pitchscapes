PitchScapes Gallery
===================

If you just want to get going, have a look at :doc:`plot_02_key_scape_plot`. For a thorough introduction, start
with the :doc:`tutorial <plot_01_tutorial>`, which walks through reading pieces, plotting pitch and key scapes,
and training pitch-scape mixture models. The other examples show individual functions in more detail. Each example can
be downloaded as a Python script or Jupyter notebook.
